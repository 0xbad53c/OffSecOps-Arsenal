# OffSecOps-Arsenal
Script de Aggressor para descargar y cargar automáticamente un arsenal de herramientas de Cobalt Strike, tanto de código abierto como privadas. Entrada de blog aquí:
https://red.0xbad53c.com/red-team-operations/offsecops/arsenal-aggressor-script


# Uso
Para utilizar esta prueba de concepto:
1. importa `OffSecOpsArsenal.cna` en Cobalt Strike
2. Abre el nuevo elemento de menú "Arsenal" y haz clic en "Download"
3. Espera a que se descarguen los repositorios y se carguen los scripts (~10 segundos en el caso del script predeterminado)
